I'm a masters student in MIT EECS (undergrad in Mathematics and Computer Science at MIT). I'm currently working on research in two different directions:

- **Formal Compiler Verification** - Adding support for vectorized x86 instructions to Fiat Crypto, a formally verified cryptography toolchain, advised by Prof. Adam Chlipala (CSAIL PLV group)
- **Poker Variants** - Studying a novel class of infinite-action space poker variants, advised by Prof. Ian Ball (Economics)

I'm interested in a wide variety of topics, but most concretely in game theory, machine learning, and decision making under uncertainty.

## Experience

**Formal Verification Research** – MIT CSAIL PLV Group (2025 - present)
- Extending [Fiat Crypto](https://github.com/mit-plv/fiat-crypto) to support vectorized instructions, improving performance of generated cryptographic code
- Modularized abstract representation of register state and proved correctness of vectorized instructions

**Game Theory & ML Research** – MIT Economics (2024 - present)
- Analytically solving Nash equilibria in simplified games, including a [family of poker variants](https://github.com/andrew-spears/poker_variant_analysis/blob/main/papers/limit_continuous_poker/main/main.pdf)
- Reinforcement learning and MCTS for large-action-space games including Poker and Coup
- Developing software tools for computational game theory problems

**Quantitative Research** – Virtu Financial (2024, 2025)
- Analyzed quote size trends using innovative feature transformations to address data correlation challenges
- Implemented rigorous train/test validation framework to ensure model reliability and prevent overfitting
- Created interactive visualizations to communicate complex statistical findings
- Built automated statistical monitoring system using correlation analysis and hypothesis testing
- Developed large-scale machine learning strategy using linear algebra techniques to interpret 100+ dimensional feature space
- Designed flow imbalance prediction model using price dislocation and market microstructure features
- Designed, simulated, and optimized market-making strategy based on flow imbalance predictions

**Machine Learning Intern** – Inkeep (May - August 2023)
- Developed tree-based clustering model for semantic question classification and packaged into reusable library
